CHARACTER CERTIFICATE DESK

START THE APP

1. Keep server.py, start-app.bat, index.html, styles.css, and app.js together.
2. Double-click start-app.bat. The app opens in your browser and loads
   Data.xlsx, school-record.txt, logo.png, and photos from the Photos folder
   automatically.
3. Keep the black command window open while using the app. Press Ctrl+C in
   that window when you are finished.
4. Use the SN range boxes to select a group, such as 1 to 10, or tick
   individual students. The list shows SN and FullName. Choose School
   completion or Grade 12 · NEB, then click Print selected. Use Clear before
   selecting another group (for example, 11 to 20 on another day).
5. In the print dialog choose A4 paper and print the selected certificates.
   The app hides the browser print headers and uses one A4 page per selected
   student. If your browser still adds a date or file address, turn off
   "Headers and footers" in the print dialog.

Python 3 and an internet connection are needed. The internet connection is
used to load the Excel-reading library. If Python is missing, install it from
https://www.python.org/downloads/ and run start-app.bat again.

FILES AND PRIVACY

Keep the school files beside the app: Data.xlsx, school-record.txt, logo.png,
and the Photos folder. Edit school-record.txt to add your school's details;
School Code appears above the logo, and Ref No. appears below it.
If Data.xlsx has a RefNo column, its value is used for Ref No. and Registration No.
You can optionally add "Short Name: Your school display name" and
"Tagline: Your school motto" to school-record.txt for the certificate header.
Student files are served only to this computer over its local address and are
not uploaded to an external server.

To replace a file for one session, expand "Replace a file manually" in the app.
